# Unique Fitness — Website Demo

Premium responsive website concept for Unique Fitness, Tondiarpet, Chennai.

## Included
- Responsive desktop/tablet/mobile layout
- Mobile navigation
- Programs section
- Membership enquiry cards
- Gallery
- FAQ
- WhatsApp enquiry form
- Call and WhatsApp CTAs
- Google Maps embed
- SEO/meta tags
- Scroll reveal animations

## Important
This is a sales/demo build. Replace sample membership copy, timings, testimonials and imagery with business-approved information before production launch.

## Local preview
Open `index.html` directly in a browser.

## Deployment
The site is static and can be deployed on GitHub Pages, Netlify or Vercel without a build step.
